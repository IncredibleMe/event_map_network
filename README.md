# Χάρτης Εκδηλώσεων Ελλάδας

Πρωτότυπο της σελίδας χάρτη για τη διπλωματική: χάρτης της Ελλάδας με πινέζες ανά τύπο εκδήλωσης,
παράθυρο λεπτομερειών με πληροφορίες και ζωντανή συνομιλία, και δυνατότητα προσθήκης νέας εκδήλωσης
με κλικ πάνω στον χάρτη.

## Εκκίνηση

Χρειάζεται Node.js 18 ή νεότερο.

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # παραγωγή στον φάκελο dist/
npm run build:preview  # ένα αυτόνομο index.html στον φάκελο dist-single/
```

## Κλειδί χάρτη (προαιρετικό)

Χωρίς κλειδί ο χάρτης φορτώνει τα tiles του OpenStreetMap και δουλεύει αμέσως.
Για το υπόβαθρο CARTO Voyager (και το σκοτεινό Dark Matter):

1. Ζήτα δωρεάν κλειδί στο https://carto.com/basemaps/apikey/ (έρχεται με email, χωρίς λογαριασμό).
2. Αντέγραψε το `.env.example` σε `.env` και γράψε `VITE_CARTO_KEY=το_κλειδί_σου`.
3. Σταμάτησε και ξαναξεκίνα το `npm run dev`.

Το `.env` είναι στο `.gitignore` και δεν ανεβαίνει στο GitHub.

## Τεχνολογίες

| Κομμάτι | Επιλογή | Γιατί |
|---|---|---|
| Γλώσσα | TypeScript | Τύποι για τα δεδομένα (MapEvent, ChatMessage) που θα μοιράζονται frontend και backend |
| UI | React 18 + Vite | Γρήγορο dev server, μεγάλο οικοσύστημα, εύκολη μετάβαση σε PWA |
| Γραφικά στοιχεία | Bootstrap 5.3 μέσω React-Bootstrap 2.10, Bootstrap Icons 1.11 | Έτοιμα κουμπιά, μπάρα, καρτέλες, φόρμες, Offcanvas για το παράθυρο εκδήλωσης, φωτεινό και σκοτεινό θέμα |
| Γραμματοσειρά | Calibri, με Carlito ως εναλλακτική | Το Calibri δεν διανέμεται ελεύθερα. Όπου δεν είναι εγκατεστημένο, φορτώνεται το Carlito από το Google Fonts (ίδιες διαστάσεις, έχει ελληνικά) |
| Χάρτης | Leaflet 1.9 μέσω react-leaflet | Απλό API, δικά μας εικονίδια με HTML/SVG, πρόσθετα για clustering και σχεδίαση |
| Υπόβαθρο | OpenStreetMap χωρίς κλειδί, ή CARTO Voyager / Dark Matter με δωρεάν κλειδί | Αλλάζει αυτόματα με το θέμα (φωτεινό ή σκοτεινό) |
| Εναλλακτικό υπόβαθρο | GeoJSON 13 περιφερειών (Natural Earth 1:10m) | Δουλεύει χωρίς σύνδεση και χρησιμεύει για φίλτρα ανά περιφέρεια |

## Πώς προσθέτω νέο τύπο εκδήλωσης

Ένα νέο αντικείμενο στο `src/eventTypes.ts` (id, label, color και ένα εικονίδιο από το `bootstrap-icons/icons/`) και το id στο `EventTypeId` του
`src/types.ts`. Πινέζες, φίλτρα και φόρμα το παίρνουν αυτόματα.

## Τι είναι ακόμα τοπικό

1. Οι εκδηλώσεις έρχονται από το `sampleEvents.ts` και όσες προσθέτει ο χρήστης μένουν στο localStorage.
2. Η συνομιλία περνάει μηνύματα μόνο ανάμεσα σε καρτέλες του ίδιου browser (BroadcastChannel).
   Τα components μιλούν με το interface `ChatService`, οπότε η υλοποίηση με Socket.IO μπαίνει χωρίς
   αλλαγές στο UI.
3. Δεν υπάρχουν λογαριασμοί χρηστών.

## Επόμενα βήματα

1. Backend σε Node.js (Express ή NestJS) με PostgreSQL και PostGIS: `GET /api/events?bbox=...`,
   `POST /api/events`, ερωτήματα τύπου «εκδηλώσεις σε ακτίνα 10 χλμ.».
2. Socket.IO με ένα room ανά εκδήλωση για τη ζωντανή συνομιλία, αποθήκευση ιστορικού στη βάση.
3. Αυθεντικοποίηση (JWT) και ρόλοι: επισκέπτης, χρήστης, διοργανωτής, διαχειριστής.
4. Clustering πινεζών με `leaflet.markercluster` όταν οι εκδηλώσεις γίνουν εκατοντάδες.
5. Πάροχος tiles για παραγωγή (MapTiler, Stadia ή δικός μας tile server), γιατί τα δημόσια tiles
   του OSM και του CARTO έχουν όρια χρήσης.
6. Επιπλέον καρτέλες στο παράθυρο: φωτογραφίες, εισιτήρια, αξιολογήσεις, ειδοποιήσεις.
